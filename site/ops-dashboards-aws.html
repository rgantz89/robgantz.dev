03 Same pattern, on this site

How this site runs

Static files in a private S3 bucket, served worldwide through CloudFront over HTTPS, with DNS and certificates managed in AWS. Every push to GitHub deploys it.

Static siteHTML, CSS, JS
Amazon S3private, OAC only
CloudFrontCDN + security headers
robgantz.devRoute 53 + ACM
deploys A push to main runs GitHub Actions. It signs in to AWS with a short-lived OIDC token, so no keys are stored, then uploads the files, clears the cache and smoke-tests the live site. Source on GitHub.
