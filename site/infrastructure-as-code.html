Infrastructure as code and SLO monitoring

I built robgantz.dev by hand on AWS, then moved every resource behind it into Terraform without changing a live setting. Changes now ship through reviewed pull requests, and a health check measures the site against a 99.9% availability target on a public status page.

01 Before and after

From console to code

The site worked, but nothing about it was repeatable or watched. That is the gap Terraform and monitoring close.

Before

by hand
  • Built by hand with the AWS CLI, one command at a time
  • Configuration existed only in the AWS account, with no history
  • Infrastructure changes needed exported admin credentials
  • No monitoring: an outage would go unnoticed until someone visited

After

as code
  • 47 AWS resources defined in Terraform and reviewed like code
  • Every change is planned on a pull request and applied only after approval
  • CI signs in with short-lived OIDC tokens, with a separate role per job
  • Every page is checked every 5 minutes, and alarms email me
02 By the numbers

What it took

03 Delivery

How a change ships

Pull requests get a read-only plan. Applying needs my approval in a protected environment, and the role that applies can only touch this project.

Pull requestformat + unit tests
Terraform planread-only role
Approvalproduction gate
AWS updatedscoped apply role
guardrails No AWS keys live in GitHub. Each job trades a short-lived OIDC token for a role that trusts only this repository: plan can read, apply can change only resources named for this project, and site deploys can only upload files and clear the cache.
04 Monitoring

How it's watched

A Lambda checks every page on a schedule and turns the results into uptime, an error budget, and a public status page.

Lambdastatus, latency, headers, cert

alerts CloudWatch alarms email me through SNS if the site fails checks for 10 minutes, if the checker itself stops reporting, if security headers disappear, or if the certificate gets within 21 days of expiring. A budget alarm flags any monthly spend over $5.
